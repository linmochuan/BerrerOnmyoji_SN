# lin RPA

`lin RPA` は、画面上の画像を認識して、マウス操作やスクリーンショットを自動実行する Windows 向けの Python RPA ツールです。Excel にタスクを記述できるため、繰り返し発生するデスクトップ操作を、コードを変更せずに管理できます。

## 主な機能

- Excel によるタスクの順次実行
- `PyAutoGUI` による画像テンプレート検索
- 複数のグローバル画像検索タスク
- マウスのクリック、押下、解放、座標オフセット
- 検索領域内のランダムクリック
- 全画面および指定領域のスクリーンショット
- GUI からの Excel、シート、信頼度、実行時間の設定
- `settings.json` による設定の保存と復元
- 停止ボタン、ウィンドウ終了、グローバルホットキーによる停止
- バックグラウンドスレッドでの実行による GUI の応答性維持

## 動作環境

- Windows
- Python 3.8 以上を推奨
- 対象アプリケーションが表示されているデスクトップ環境
- 画面キャプチャとマウス操作を許可した Python 環境

## インストール

```bash
pip install -r requirements.txt
```

主なライブラリは次のとおりです。

- `PyAutoGUI`：画面上の画像検索、マウス操作、スクリーンショット
- `openpyxl`：Excel タスクの読み込み
- `PyYAML`：YOLO クラスとアクション設定の読み込み
- `tkinter`：Windows GUI
- `pynput`：グローバルキーボードショートカット
- `numpy`：ランダム座標と画像データ処理
- `torch`、`opencv-python`、`mss`：YOLO 実験スクリプトと画面検出
- `pyinstaller`：Windows 実行ファイルの作成

## 起動方法

```bash
python lin_RPA.py
```

起動後、次の項目を設定します。

1. Excel ファイルを選択します。
2. 対象のワークシートを選択します。
3. スクリーンショット保存先を設定します。
4. 画像検索の信頼度を設定します。
5. 実行時間を分単位で入力します。`0` は継続実行です。
6. 「開始」をクリックします。

実行中は「停止」ボタン、設定済みのグローバルホットキー、またはウィンドウ終了でタスクを停止できます。

## Excel タスク形式

プログラムは 1 行目をヘッダーとして扱い、2 行目から 4 列を読み込みます。

| 列 | 項目 | 説明 |
| --- | --- | --- |
| A | 画像パス | 検索対象のテンプレート画像。相対パスまたは絶対パスに対応します。 |
| B | 操作コマンド | 複数のコマンドは全角カンマ `，` で区切ります。 |
| C | 検索時間 | 秒数を指定します。空欄は 10 秒です。`全局查找` と入力すると継続検索になります。 |
| D | タイムアウト動作 | `skip` でスキップ、数字で指定行へ移動します。 |

例：

| 画像パス | 操作コマンド | 検索時間 | タイムアウト動作 |
| --- | --- | ---: | --- |
| `data/images/start.png` | `等待=0.5，左键=1` | 10 | `skip` |
| `data/images/button.png` | `偏移=10/5，二级左键=2` | 8 | `2` |
| `data/images/notice.png` | `左键=1` | `全局查找` | |

相対パスはプロジェクトのルートディレクトリを基準に解決されます。画像は対象アプリケーションの現在の表示倍率と一致するように用意してください。

## 操作コマンド

| コマンド | 例 | 動作 |
| --- | --- | --- |
| 待機 | `等待=1.5` | 指定秒数待機します。 |
| 座標オフセット | `偏移=10/5` | 以降の座標を右へ 10、下へ 5 ピクセル移動します。 |
| 左クリック | `左键=2` | 画像の中心を 2 回クリックします。 |
| ランダムクリック | `二级左键=3` | 画像領域内のランダムな位置を 3 回クリックします。 |
| オフセットクリック | `三级左键=10/20/1` | 中心から `(10, 20)` 移動した位置を 1 回クリックします。 |
| 左ボタン押下 | `左键按下` | 左ボタンを押します。 |
| 左ボタン解放 | `左键释放` | 左ボタンを解放します。 |
| 右ボタン押下 | `右键按下` | 右ボタンを押します。 |
| 右ボタン解放 | `右键释放` | 右ボタンを解放します。 |
| 全画面保存 | `屏幕截图` | 現在の画面を保存します。 |
| 範囲保存 | `区域屏幕截图=0/0/800/600` | 指定範囲を保存します。 |

例：

```text
偏移=15/8，等待=0.5，左键按下，等待=1，左键释放
```

## グローバル画像検索

Excel の C 列に `全局查找` を設定した行は、通常の順次タスクとは別に、プログラムの実行中ずっと画像を検索します。

- A 列の画像パスと B 列の操作コマンドは通常タスクと同じです。
- 複数の行に `全局查找` を設定できます。
- 複数の画像を同時に監視できます。
- 同じ画像が表示され続けている間は 1 回だけ操作します。
- 画像が一度消えてから再び表示された場合は、もう一度操作します。
- グローバル検索の継続ログは出力しないため、実行ログが過度に増えません。

## RPA モジュール構成

```text
lin_RPA.py
    GUI、入力値の検証、開始・停止、ログ表示

rpa_readers.py
    settings.json、Excel、YAML の読み込みと画像パス解決

rpa_operations.py
    マウス、キーボード、スクリーンショット、画像検索、停止信号

rpa_executor.py
    ExcelExecutor によるタスク実行、通常検索、グローバル画像検索
```

### モジュール間の連携

```text
GUI の設定
    -> settings.json と Excel の読み込み
    -> ExcelExecutor をバックグラウンドで起動
    -> 画像テンプレートを検索
    -> 画像の中心座標を計算
    -> B 列の操作コマンドを順番に実行
    -> マウス操作、キーボード操作、スクリーンショット
    -> ログを GUI に表示
    -> 実行時間または停止信号で終了
```

## 設定ファイル

### `settings.json`

置信度は `settings.json` の `confidence` から読み込みます。`lin.txt` は使用しません。

```json
{
    "confidence": 0.8,
    "excel_path": "D:/rpa/tasks.xlsx",
    "sheet_name": "Sheet1",
    "screenshot_path": "D:/rpa/screenshots",
    "hotkey": ["CTRL", "Q"],
    "model_path": "best.pt"
}
```

### その他のファイル

- `best.pt`：YOLO の学習済みモデル
- `data/onmyoji.yaml`：YOLO クラス名
- `data/onmyoji_name.yaml`：クラス名の日本語・中国語表示用マッピング
- `data/3leader.yaml`：YOLO クラスとアクションの設定
- `lin.xlsx`：Excel タスクの例
- `output/`：スクリーンショットの保存先として利用可能なディレクトリ

## YOLOv5 について

このリポジトリには YOLOv5 の検出、分類、セグメンテーション、検証、エクスポート用コードも含まれています。`best.pt` を使用した実験スクリプトとして `J1.py`、`W2.py`、`W3.py`、`jc.py` などを保守しています。

ただし、現在の `lin_RPA.py` の GUI が起動するメイン機能は Excel 線形タスクです。Excel の `全局查找` は YOLO クラス検出ではなく、画像テンプレートの継続検索です。

## ビルド

PyInstaller で Windows 実行ファイルを作成できます。

```bash
pyinstaller lin_RPA.spec
```

生成されたディレクトリ全体を移動してください。実行ファイルだけを移動すると、モデルや YAML 設定が見つからない場合があります。

## 注意事項

- 対象アプリケーションを起動してから RPA を開始してください。
- Windows の表示倍率、ウィンドウサイズ、解像度がテンプレート画像と一致していることを確認してください。
- 最初は `左键=1` のような単純なコマンドで座標を確認してください。
- 長い `等待=...` は停止処理を遅らせるため、短い待機に分割してください。
- マウスボタンを押下するコマンドを使用する場合は、対応する解放コマンドも設定してください。
- RPA と YOLO 実験スクリプトを同時に実行しないでください。複数のプロセスが同時にマウスを操作する可能性があります。
